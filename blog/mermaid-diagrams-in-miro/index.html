Quick Answer

Paste Mermaid code straight onto a Miro board, or open Formats > Diagram > Build with code, and Miro turns it into a diagram. Flowcharts become real Miro shapes you can edit on the canvas, and the code updates as you edit. If you use an AI coding tool such as Claude Code or Cursor, connect it to the Miro MCP server and ask it to draw the diagram for you, for example an architecture map of your repository. Mermaid and MCP are listed on every Miro plan, including Free.

What Mermaid Is, in 30 Seconds

Mermaid is a text format for diagrams. You describe boxes and arrows in a few lines, and a renderer draws them. Here is a complete flowchart of how a support chatbot might hand a ticket to a human:

flowchart TD
    A[Customer message] --> B{Can the bot answer?}
    B -- Yes --> C[Bot replies]
    B -- No --> D[Create ticket]
    D --> E[Assign to support agent]
    E --> F[Agent replies]
    C --> G((Done))
    F --> G

Because it's plain text, Mermaid lives happily in README files, pull requests, docs and AI chats. ChatGPT, Claude and most coding assistants write it well. The weak spot has always been collaboration: a rendered Mermaid image is static, so non-technical teammates can't comment on it or move things around. That's the gap Miro's Mermaid support is built to close.

Walkthrough: From Code to an Editable Diagram

These steps follow Miro's own guide. Use the chatbot flowchart above if you want something to practise with.

  1. Open a board and click the Creation bar on the left.
  2. Choose Formats, then Diagram, and click Build with code.
  3. Paste your Mermaid code into the code panel, or choose one of the Mermaid templates. The diagram renders as Miro shapes with an automatic layout.
  4. Open it in focus mode to edit. Select a shape, line or label and change it directly, switch the layout direction (top to bottom, left to right) or adjust spacing from narrow to wide.
  5. Edit the code if you prefer. Open the code panel and change the syntax. Miro keeps the code and the diagram in sync both ways, so whichever you edit, the other follows.
  6. Add meaning. Colour-code shapes to show status, an incident path or what's changing, then invite teammates to comment right on the diagram.
  7. Close the loop. Copy the Mermaid code back into your repo or docs, export the diagram as JPG, SVG or PDF, or share a focus-mode link.

The two-way sync is the part worth noticing. With most Mermaid tools, someone edits the picture and the code goes stale, or the code changes and the picture in the slide deck doesn't. In Miro, the code panel and the board are the same object.

Let an AI Agent Draw It Through Miro MCP

MCP (Model Context Protocol) is the standard way AI assistants connect to outside tools. Miro runs an MCP server that lets an assistant read your boards and write to them, including Mermaid diagrams. Miro names Claude, Claude Code, Cursor, VS Code and Lovable as supported clients.

How the connection works

  1. Add the Miro MCP server in your AI client. Follow the client-specific setup in Miro's help center, because each client adds servers slightly differently.
  2. Authorize with OAuth. You sign in to Miro and choose what the assistant can reach. On Free, Starter and Business plans, MCP access is already switched on and only needs your authorization.
  3. On Enterprise, a company admin has to enable Miro MCP first, and can limit it to certain teams or user groups.
  4. Ask for a diagram and give the assistant a board link to write to.

Prompts worth trying

The most useful requests are the ones that are tedious to draw by hand. A few starting points:

Read this repository and draw a flowchart of the main services
and the calls between them on this Miro board: [board link]

Turn the checkout logic in /src/payments into a Mermaid flowchart
on the board, and colour the error paths red.

Read the diagram on [board link] plus the team's comments, then
draft an architecture decision record I can open as a pull request.

Miro's own demo shows Claude Code reading a repository end to end and building an editable architecture diagram on a board. The last prompt above is the round trip Miro describes: an agent writes the diagram, people discuss it on the board, and another agent reads the diagram and comments back to update docs or code. When an agent changes a diagram, Miro says it can add a legend marking what it added, removed or changed, which makes AI edits easier to review.

Treat AI-drawn architecture diagrams like AI-written code: check them against the source before you share them as the truth. If you're choosing an assistant for this kind of work, our Claude review, Cursor review and best AI coding tools list compare the main options.

For sequence diagrams, for example, you can still paste the code and get a correct diagram on the board, but you'll change it by editing the code rather than by dragging shapes. Here's a short one to try:

sequenceDiagram
    participant U as User
    participant A as App
    participant P as Payment API
    U->>A: Click "Pay"
    A->>P: Create charge
    P-->>A: Charge succeeded
    A-->>U: Show receipt

Miro says Mermaid code can run to 30,000 lines and that it has tested flowcharts with more than 500 nodes, with no hard limit on how many Mermaid diagrams a board holds.

Limits to Know Before You Rely on It

  • No free placement. Mermaid diagrams use Miro's automatic layout, so you can't drag a single shape to an exact spot. You choose direction and spacing, and Miro does the rest. If pixel-perfect placement matters, draw that diagram with regular Miro shapes instead.
  • Only flowcharts are fully editable today. Sequence, class, state and ER diagrams are listed as coming soon; everything else stays an SVG.
  • The Free plan is small. Three editable boards and a handful of AI credits is enough to try the feature, not to run a team's documentation on it.
  • Enterprise needs an admin. MCP is off until an admin enables it, which is sensible for security but adds a step.
  • MCP has daily limits. Miro says MCP is on all plans but with a different maximum number of API calls per day on each, so heavy agent use may push you to a higher plan.

Who Should Use It

  • Engineering teams that already keep Mermaid in their repos and want product managers and designers to comment without learning the syntax.
  • Developers using Claude Code, Cursor or VS Code who want architecture and flow diagrams generated from real code instead of drawn from memory.
  • Product and ops people who'd rather describe a process to an AI assistant than drag boxes around, then tidy the result on the board.

If you only need a quick diagram in a README and nobody else will touch it, a free Mermaid renderer is enough. Miro earns its place when the diagram has to be discussed, changed by several people and kept in sync with the code.

FAQ

Does Miro support Mermaid?

Yes. Miro renders Mermaid code as a Diagram on the board. Flowcharts become native, editable Miro shapes; other Mermaid diagram types render as Mermaid SVG for now, with native state, sequence, class and ER diagrams listed as coming soon in Miro's help center.

Is Mermaid in Miro free?

Miro's pricing page lists Mermaid diagrams and MCP on every plan, including Free. The Free plan is limited to 3 editable boards and a small monthly allowance of AI credits. Paid plans start at $8 per member per month billed yearly.

Can I edit a Mermaid diagram visually in Miro?

Yes, for flowcharts. Changes you make on the board update the Mermaid code, and changes to the code re-render the diagram. Miro handles the layout automatically, so you can't drag individual shapes anywhere you like.

Which AI tools can draw Mermaid diagrams on a Miro board?

Any client that connects to the Miro MCP server. Miro names Claude, Claude Code, Cursor, VS Code and Lovable. You authorize the connection with OAuth; on Enterprise plans an admin has to enable Miro MCP first.

Can I get my Mermaid code back out of Miro?

Yes. You can copy the Mermaid syntax from the code panel back into your docs or repository, or export the diagram as JPG, SVG or PDF.
