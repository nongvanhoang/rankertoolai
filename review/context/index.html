Our Verdict

Context.dev has grown from a scraping-plus-brand-data API into a broader web data layer for AI agents: scrape, crawl, map, batch, search, sourced Answers, page monitors, people and company search, and brand intelligence, all on one credit balance. The 2026 price changes made it cheaper to start: the free plan doubled to 1,000 credits, Developer dropped to $20/month for 5,000 credits, and Pro dropped to $90/month for 100,000 credits. It also gained an MCP server and a CLI, so you can wire it into Claude Code or Cursor in one command. The weak spot is still cost forecasting: endpoints range from 1 credit (plain scrape) to 10 (brand data) and 100 (an Ultra answer), so two teams on the same plan can see very different bills. If you mostly need brand data or a mix of scraping, search and monitoring, it is one of the more complete options we've reviewed. If you only need plain page-to-Markdown, Firecrawl costs about the same and is worth comparing.

How we reviewed it: this is a research-based review, not a hands-on lab test. Plans, credit costs, limits and features come from Context.dev's pricing page, docs and homepage, re-checked on November 11, 2026. Key Features

Scrape, Crawl, Map and Batches

Send a URL and get Markdown, HTML, structured JSON fields (against a schema you define), images or a screenshot, from web pages and PDFs. Every request runs in a real browser, and blocked requests are retried automatically with a stronger proxy. Crawl discovers and scrapes up to 500 pages in one call with controls for depth, URL patterns and subdomains. Map returns just the URLs, and Batches run thousands of URLs in the background with a webhook when the job finishes.

Search, Answers and Highlights

Web and news search return ranked results with page content, not just links. The Answers API (launched September 2026) takes a research question and returns structured JSON in the shape you ask for, with the source URLs behind it. Fast mode costs 10 credits and Ultra costs 100. Highlights returns only the passages of a page that match your query, which helps keep agent prompts short.

Monitors

Monitors check pages on a schedule and send a webhook when content changes, for example a competitor's pricing page. The free plan includes 10 monitors, Developer 100 and Pro 1,000. Context.dev recently added web search monitors as well.

Brand Intelligence

Give it a domain and it returns the logo, brand colors, fonts, a styleguide and a company profile (industry, location, social links). The typical use is autofilling a signup form from a work email domain. Logo Link is a separate image URL for logos that doesn't use API credits and has its own quota. Brand data may be cached for up to about 90 days by default; you can request a fresh pull.

People and Company Data

Newer endpoints let agents search companies (from 2 credits), search people (from 10 credits) and enrich a person (20 credits per match). This puts Context.dev partly into enrichment-tool territory, though it's still primarily a web data API.

Getting Started in Five Minutes

  1. Sign up on the free plan to get an API key (no card).
  2. Pick an interface: install an SDK (for example npm install context.dev), use the CLI, or connect the MCP server.
  3. In Claude Code, the MCP connection is one command: claude mcp add --transport http --scope user context https://mcp.context.dev/mcp. Other MCP clients can add https://mcp.context.dev/mcp directly.
  4. Run a test scrape on one page, then check key_metadata.credits_consumed in the response to see what it cost.
  5. Estimate your month by multiplying the per-call credits for each endpoint you'll use, then compare against the plan table above.

Who Should Skip Context.dev

  • You only need plain page-to-Markdown at low volume. Firecrawl's $19 plan or the free tier of either tool may be all you need.
  • You need one-off data pulls. There are no one-time lookups; it's monthly or annual subscription only.
  • You want fixed, predictable bills with heavy Ultra Answers or people enrichment. At 100 and 20 credits per call, these eat credit balances fast.
  • You need very high scraping volume with your own proxy control. Infrastructure providers like Bright Data give more control, with more setup.

Primary Use Cases

  • Grounding RAG systems with fresh pages from Scrape and Crawl, kept current with Monitors.
  • Autofilling onboarding forms with a company's logo, colors and details from a work email domain.
  • Giving AI agents web access through the MCP server: search, read pages, take screenshots.
  • Company research and enrichment with Answers and company/people search for sales or CRM tools.
  • Tracking competitor pages such as pricing and changelogs with scheduled monitors.

Context.dev Alternatives

  • Firecrawl: the closest competitor, focused on scraping, crawling and search for LLMs, without brand data.
  • Apify: a broad marketplace of pre-built scrapers ("Actors"), better for site-specific scraping jobs, steeper for simple use.
  • ScrapingBee: a simpler render-and-proxy API if you only need raw HTML.
  • Bright Data: enterprise proxy and scraping infrastructure for very high volume, with heavier setup.

Frequently Asked Questions

What is Context.dev?

Context.dev is a web data API built for AI agents and LLM apps. One API key covers scraping (any page or PDF to Markdown, HTML, JSON fields, images or screenshots), crawling and URL mapping, web and news search, an Answers API that returns structured, sourced research, scheduled page monitors, and brand intelligence (logo, colors, fonts, styleguide and company profile from a domain).

Does Context.dev have a free plan?

Yes. The free plan includes 1,000 credits per month (about 1,000 standard scrapes), 2 concurrent requests, 10 monitors and a one-time quota of 10,000 Logo Link requests, with no credit card. There is no overage on the free plan: when credits run out, requests return a USAGE_EXCEEDED error until the next month.

How much does Context.dev cost?

As of November 2026: Developer is $20/month for 5,000 credits, Pro starts at $90/month for 100,000 credits (with larger credit tiers), Growth is $300/month, Scale is $500/month and Scale 2.5M is $950/month. Enterprise is custom above 2.5M credits/month. Annual billing gives two months free, and eligible startups and nonprofits can apply for 30% off an annual plan for 12 months. Check Context.dev's pricing page before buying, since plans changed during 2026.

How many credits does each Context.dev API call use?

A standard scrape is 1 credit (2 with browser actions). Scrape with JSON extraction is 5 credits per page. Crawl is 1 credit per page. Brand retrieval and styleguide extraction are 10 credits. Answers costs 10 credits in Fast mode or 100 in Ultra. Web and news search start at 1 credit per 10 results, People Search is 10 credits per call and Person Enrich is 20 credits per match. JS rendering, proxies and anti-bot handling are included in the base price.

Context.dev vs Firecrawl: which is cheaper?

At the entry level they are close: Context.dev Developer is $20/month for 5,000 credits and Firecrawl Hobby is $19/month for 5,000 credits. At around 100,000 credits Context.dev Pro is $90/month with 100 concurrent requests, while Firecrawl Standard is $99/month with 25 concurrent requests. Context.dev also includes brand data APIs that Firecrawl does not offer. Compare the credit cost of the specific endpoints you plan to use before deciding.

Can I use Context.dev from Claude Code, Cursor or other AI coding tools?

Yes. Context.dev publishes an MCP server at https://mcp.context.dev/mcp (Claude Code: claude mcp add --transport http --scope user context https://mcp.context.dev/mcp), a CLI, and official SDKs for TypeScript, Python, Ruby, Go and PHP. Agents can also sign up programmatically through its auth.md guide, though a human still has to verify the email.
